Topic: RAM Fundamentals (BCA Semester 1)

1. Definition

RAM (Random Access Memory) is the main volatile memory of a computer system. It temporarily holds data and running application instructions for quick CPU access. All data is lost when power turns off.

2. Real-Life Example 💡

Think of RAM like your study desk. You keep books on it that you are currently reading for fast access. When you finish studying (power off), you clear the desk.

9. Exam Questions

Q1: Difference between Volatile and Non-Volatile Memory?

Answer: Volatile memory (like RAM) loses data without electricity. Non-volatile memory (like ROM) retains data permanently even without power.
