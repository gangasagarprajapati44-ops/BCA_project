Detailed Topic Explanation & Notes

Introduction: Primary memory is essential for computer operations. It allows the processor to access data directly from the main memory modules.

Key Concepts:

  • RAM (Random Access Memory): Volatile memory used for temporary execution data.
  • ROM (Read-Only Memory): Non-volatile memory containing permanent firmware instructions (BIOS).

Important Exam Questions (Short & Long)

Q1. (Short) Define Volatile Memory with an example.

Answer: Volatile memory requires power to maintain stored information. Example: RAM loses all data when the device is powered off.

Q2. (Long) Explain the architectural differences between RAM and ROM in detail.

Answer: RAM is read-write memory interfacing directly with CPU caches for fast processing cycles. In contrast, ROM is read-only storage utilizing mask ROM, PROM, or EPROM technologies designed to securely hold boot-up routines.
