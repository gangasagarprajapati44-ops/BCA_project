विषय: RAM vs ROM (Semester 1)

RAM का मतलब Random Access Memory है। यह कंप्यूटर की मुख्य मेमोरी होती है जो बहुत तेज़ होती है। जब आप कंप्यूटर पर कोई काम करते हैं, तो वह डेटा अस्थायी रूप से RAM में स्टोर होता है। कंप्यूटर बंद होने पर RAM का सारा डेटा डिलीट हो जाता है। दूसरी तरफ, ROM का मतलब Read Only Memory है। यह एक स्थायी मेमोरी है। इसमें कंप्यूटर को चालू करने के लिए ज़रूरी निर्देश पहले से लिखे होते हैं। कंप्यूटर बंद होने पर भी ROM का डेटा डिलीट नहीं होता है।
